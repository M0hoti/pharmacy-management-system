# Pharmacy Management System

A web-based pharmacy management system built using PHP, MySQL, HTML, CSS, and JavaScript.

## Features
- User registration and login
- Medicine stock management
- Nearest pharmacy search using GPS location
- Medicine ordering
- Order approval and delivery management

## Technologies Used
- PHP
- MySQL/MariaDB
- HTML
- CSS
- JavaScript
- XAMPP

## Setup Instructions
1. Install XAMPP.
2. Place the project folder inside `htdocs`.
3. Start Apache and MySQL.
4. Import `database/pharmacy_db.sql` into phpMyAdmin.
5. Open `http://localhost/pharmacy-system/`.
